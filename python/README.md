# 🐍 Python

Python est **le** langage du hacker : rapide à écrire, parfait pour automatiser et scripter des attaques en CTF.

## 🗺️ Par où commencer ?

1. [Les bases](bases/bases_python.md) — variables, conditions, boucles, fonctions
2. [Bytes & encodage](bytes/bytes_encodage.md) — manipuler des données brutes (indispensable pour la crypto)

## ⚙️ Installation rapide

```bash
python3 --version          # vérifier que Python est installé
python3 -m venv .venv      # créer un environnement virtuel
source .venv/bin/activate  # l'activer
pip install pwntools       # installer une lib (ici la référence en CTF)
```
